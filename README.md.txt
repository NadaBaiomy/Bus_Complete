# 🚌 أتوبيس كومبليت — Bus Complete

لعبة الحروف والفئات العربية الشهيرة، مبنية بـ HTML/CSS/JavaScript خالصة في ملف واحد قابل للنشر مباشرة على GitHub Pages أو أي استضافة ثابتة.

## ✨ المميزات

### 🎮 أنظمة اللعب الأربعة
1. **اللعب الفردي ضد الكمبيوتر** — تحدَّ من 1 إلى 3 لاعبين يتحكم بهم الذكاء الاصطناعي.
2. **اللعب مع الأصدقاء على جهاز واحد (Pass & Play)** — من 2 إلى 6 لاعبين بالتناوب.
3. **اللعب أونلاين مع الأصدقاء** — أنشئ غرفة خاصة، شارك الكود، والعب حتى 50 لاعبًا.
4. **التحدي اليومي** — حرف وفئات جديدة كل يوم مع سجل لأفضل النتائج.

### 🎯 المنطق الكامل
- اختيار حرف عشوائي من الحروف العربية (مع إمكانية استبعاد الحروف الصعبة: ث، ذ، ظ، ض).
- مؤقت تنازلي قابل للتخصيص (45 / 60 / 90 / 120 ثانية).
- جدول إجابات بـ 8 فئات افتراضية + 8 فئات إضافية قابلة للاختيار.
- زر "أتوبيس كومبليت 🚌" لإنهاء الجولة عند الانتهاء.
- نظام نقاط مرن (10 للفريدة / 5 للمكررة / 0 للخاطئة) قابل للتعديل.
- شاشة مراجعة يدوية للإجابات قبل اعتماد النتائج.
- كشف تلقائي للإجابات التي لا تبدأ بالحرف.
- شاشة نتائج بعد كل جولة + شاشة نتائج نهائية مع متوّج وكونفيتي.

### 🤖 ذكاء اصطناعي حقيقي
- قاموس مضمّن بكلمات عربية صحيحة لكل حرف وكل فئة.
- الكمبيوتر يختار إجابات صحيحة تبدأ بالحرف وتنتمي للفئة.
- تنوع في إجابات الكمبيوتر (لا تكرار داخل الجولة الواحدة).
- أحيانًا يترك الكمبيوتر بعض الفئات فارغة لمحاكاة اللاعب البشري.

### 🌐 لعب أونلاين حقيقي
- استخدام **PeerJS** (WebRTC P2P) للاتصال المباشر بين الأجهزة.
- لا حاجة لخادم خلفي — كل البيانات تمر بين الأجهزة مباشرة.
- المضيف يدير الحرف والمؤقت والإعدادات ويزامن الحالة مع الجميع.
- كود غرفة مكوّن من 6 أحرف سهل المشاركة.
- دعم حتى 50 لاعبًا في الغرفة الواحدة.

### 🎨 التصميم
- واجهة عربية كاملة RTL بخط **Cairo** العصري.
- تصميم متجاوب يعمل على الموبايل والكمبيوتر.
- ألوان عصرية (بنفسجي/وردي/أصفر) مع تدرجات لونية.
- مؤثرات صوتية اختيارية (Web Audio API) + اهتزاز على الموبايل.
- كونفيتي عند الفوز، انتقالات سلسة بين الشاشات.

### ⚙️ الإعدادات القابلة للتخصيص
- تفعيل/إيقاف المؤثرات الصوتية والاهتزاز.
- تعديل نظام النقاط (الفريدة / المكررة / الخاطئة).
- تفعيل مهلة إضافية بعد "أتوبيس كومبليت".
- استبعاد الحروف الصعبة.
- حفظ كل الإعدادات محليًا (localStorage).

## 🚀 طريقة التشغيل محليًا

### الطريقة الأبسط
1. حمّل ملف `bus-complete.html`.
2. افتحه بأي متصفح حديث (Chrome، Firefox، Safari، Edge).
3. ابدأ اللعب فورًا! 🎉

### عبر خادم محلي (اختياري لأداء أفضل)
```bash
# باستخدام Python
python3 -m http.server 8000

# أو باستخدام Node.js
npx serve

# ثم افتح المتصفح على:
# http://localhost:8000/bus-complete.html
```

## 📤 النشر على GitHub Pages

### الخطوات
1. **أنشئ مستودعًا جديدًا على GitHub** باسم مثل `bus-complete`.
2. **ارفع ملف `bus-complete.html`** إلى المستودع:
   ```bash
   git clone https://github.com/USERNAME/bus-complete.git
   cp bus-complete.html bus-complete/
   cd bus-complete
   git add bus-complete.html
   git commit -m "إضافة لعبة أتوبيس كومبليت"
   git push origin main
   ```
3. **فعّل GitHub Pages**:
   - اذهب لإعدادات المستودع → **Settings** → **Pages**.
   - في قسم **Source**، اختر فرع `main` ومجلد `/ (root)`.
   - اضغط **Save**.
4. **انتظر دقيقة** ثم افتح الرابط:
   ```
   https://USERNAME.github.io/bus-complete/bus-complete.html
   ```

### نصيحة: ملف index.html
لجعل الرابط أقصر (`https://USERNAME.github.io/bus-complete/`)، أنشئ ملف `index.html` يحوّل إلى اللعبة:
```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>أتوبيس كومبليت</title>
</head>
<body>
  <meta http-equiv="refresh" content="0; url=bus-complete.html">
</body>
</html>
```

## 🎮 كيف تلعب؟

### القواعد
1. يختار النظام حرفًا عربيًا عشوائيًا.
2. على كل لاعب كتابة كلمة لكل فئة تبدأ بالحرف المختار.
3. الفئات الافتراضية: ولد، بنت، حيوان، نبات، جماد، بلاد، أكل، مهنة.
4. عند الانتهاء، اضغط زر "🚌 أتوبيس كومبليت!".
5. إذا انتهى الوقت، تُحفظ الإجابات المكتوبة فقط.

### نظام النقاط
| الحالة | النقاط |
|---|---|
| إجابة صحيحة وفريدة (لم يكتبها أحد غيرك) | 10 |
| إجابة صحيحة مكررة عند أكثر من لاعب | 5 |
| إجابة خاطئة أو خانة فارغة | 0 |
| إجابة لا تبدأ بالحرف | تُرفض تلقائيًا |

### اللعب أونلاين
1. اضغط "العب أونلاين مع الأصدقاء".
2. المضيف: اضغط "إنشاء غرفة" واحصل على كود من 6 أحرف.
3. شارك الكود مع أصدقائك (واتساب، تيليجرام، إلخ).
4. الأصدقاء: أدخل اسمك والكود واضغط "انضمام".
5. عندما يجتمع الجميع، يضغط المضيف "بدء المباراة".

> 💡 **ملاحظة عن الاتصال:** تستخدم اللعبة PeerJS للاتصال المباشر بين الأجهزة عبر الإنترنت. لا حاجة لتسجيل دخول أو خادم. إذا انقطع الاتصال، أعد المحاولة.

## 🏗️ بنية الكود

الملف الواحد مقسّم منطقيًا إلى:

```
bus-complete.html
├── <style>      — كل الـ CSS (تصميم عصري RTL)
├── <body>       — شاشات HTML (Home, Setup, Lobby, Game, Review, Results, Final, ...)
└── <script>     — منطق اللعبة
    ├── الثوابت          — الحروف، الفئات، الصور الرمزية
    ├── AI_DICTIONARY    — قاموس الكلمات لكل حرف/فئة
    ├── state            — حالة اللعبة المركزية
    ├── sound            — المؤثرات الصوتية (Web Audio)
    ├── إدارة الشاشات    — showScreen, navigation
    ├── الإعدادات         — load/save settings
    ├── منطق اللعب        — pickLetter, startTimer, renderGameScreen
    ├── نظام النقاط       — calculateScores, validate
    ├── الذكاء الاصطناعي  — generateAIAnswers
    ├── اللعب المحلي       — pass-and-play
    ├── اللعب أونلاين     — PeerJS, createRoom, joinRoom, broadcast
    └── التحدي اليومي     — getDailyChallenge, leaderboard
```

## 🛠️ التخصيص

### إضافة فئة جديدة
في مصفوفة `ALL_CATEGORIES`:
```javascript
{ id: 'فيلم', label: 'فيلم', icon: '🎬' },
```

### إضافة كلمات للقاموس
في كائن `AI_DICTIONARY`، تحت الحرف المطلوب:
```javascript
'س': {
  'فيلم': ['سفاري', 'سايلنت هيل', ...],
  ...
}
```

### تغيير الألوان
في متغيرات CSS `:root`:
```css
:root {
  --primary: #6B46C1;   /* اللون الأساسي */
  --secondary: #EC4899; /* اللون الثانوي */
  --accent: #FBBF24;    /* لون التمييز */
}
```

## 🔧 استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| اللعب أونلاين لا يعمل | تأكد أن المتصفح يسمح بـ WebRTC، وأن الشبكة لا تمنع WebRTC (بعض الشبكات المؤسسية تمنعه). |
| الخط لا يظهر بشكل عربي | تأكد من اتصال الإنترنت (الخط يُحمّل من Google Fonts). |
| الإجابات تظهر باللون الأحمر | هذا طبيعي — يعني أن الإجابة لا تبدأ بالحرف المطلوب. |
| لا أسمع المؤثرات الصوتية | فعّل الصوت من الإعدادات، وتأكد أن المتصفح يسمح بالصوت. |
